# /summarize

Summarize the current session, update project tracking, and prepare for handoff.

## Workflow

1. Review the work done in this session.
2. Append a concise handoff note to the Session Notes in `docs/ROADMAP.md`.
3. Run `./scripts/sync.sh` so linting and the repo map stay current.
4. Provide a short saved-state summary with the current milestone, completed work, and next suggested step.
